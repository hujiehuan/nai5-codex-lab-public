# v0.5.5 总实验室

升级前完全退出程序，在自己的 Mac 上备份整个应用数据目录。按 [本机只读校验](LOCAL_DATABASE_CHECK.md) 在升级前后比较决策；不上传 library.db。本版没有新增 SQLite migration，实验资料保存在应用目录的 `studio/`，不会写入筛选决策。

## 使用

导航只保留一个「总实验室」。旧 `/reverse`、`/lab/draw` 路径打开对应模式；旧历史通过总实验室历史入口查看，不会转换或删除旧记录。

每轮先确定共同输入，再展开模型 × skill 组合。每行单独显示构思、出图、错误与停止状态。新构思会消耗模型 API；检查完整提示词后再出图。实验室不主动重试失败构思或切换候补模型；AstrBot 适配器/上游 SDK 自身可能有传输恢复，不能把一次构思等同于一次 HTTP 请求。网络不明确的出图重试沿用同一 request_id 防止重复生成。停止不会撤回远端已接收的工作。

- **反推**：上传原图，选一个或多个反推提示词模型；可编辑普通/分别反推模板、选择评分模型、精准画风候选复审。候选张数表示同方案多次采样；与 /画 的多构思区分。为了统一免费保护，新实验使用三档免费尺寸，与插件 `/反推` 指令的可配置尺寸可能不同。分别反推宜明确填入有序人物名单，减少模型识别人数差异对实验的干扰。
- **/画**：选择 include 或 all 决策范围的 safe 图包，全量或抽样参考；角色空时从插件角色池选取后冻结。张数为多个不同构思，每个均须落实同一自然语言要求。多人角色与简报独立填写，线上默认配置不被覆盖。
- **画风复审**：选2张以上图片，图 1 固定为基准。每个视觉 LLM 一次查看全部输入，从其余候选中返回画风最接近的前三名、批内相似度和具体依据；常用 8 张时即从图 2–8 排出前三。三个本地编码器仍输出全部图对的余弦相似度，人工组标签为空则不计算该对准确率。视觉模型与本地编码器分开展示，分数不跨模型直接比较，也不能证明用了同一画师串。详见 [画风评测依据](STYLE_BENCHMARK.md)。

## Skill 材料

内置 `nai5-prompting`：本仓库原创的简短 NAI5 提示词写法说明（`resources/prompting-guide/GUIDE.md`，随应用代码按 MIT 许可，版本 `builtin-1`）。可单独选用、与另一份组合，也可建立无 skill 对照。

「导入 NPE 固定版」从 [RefirmSaky 上游](https://github.com/RefirmSaky/novelai-prompt-design-enhancer/tree/58f98acfbc9b7556258a294183ef46057e00afb1) 下载主 SKILL 与设计参考到 Mac 私有目录，固定 revision `58f98acfbc9b7556258a294183ef46057e00afb1`，不下载示例图片或可选画师库。上游未提供明确分发许可证，本仓不内置其全文。导入后可查看正文、来源、版本、字节数和 SHA256。

这里将选中的材料完整放入 LLM 请求；不会在服务器执行技能里的命令，也不冒充 NPE Agent 原来的按需读文件流程。应用的角色、画风选择、硬要求、结构化输出和免费约束优先。单份材料上限768 KiB，组合1 MiB；参考正文2 MiB。超限明确失败，不截断。选定组合后在方案里保留完整快照，后续删除导入项不会改旧方案。

## 连接、费用与图片

插件端需要本次配套 v2.0.2 的 `/page/lab/studio/*` 接口，更新代码后由用户在 AstrBot 中重载插件。仍使用现有 WebUI 登录与 Library Token；没有重新保存密钥或扩大文件权限。桌面本地技能、图包读取和已缓存历史不需要调用 LLM。

出图只走 V5、832×1216 / 1216×832 / 1024×1024、最多28步及逐张免费资格校验；不足或无法读取余额时停止，不回退到付费生图。无法提供服务端原子零扣费保证，费用未核实时显示未知。构思、评分、视觉复审为额外模型 API 费用。

JPEG 为原 PNG 的衍生副本，默认质量88、4:4:4，可以调整。两份都保留，显示实际大小；有损压缩不承诺所有图片更小或肉眼无差别，原始 PNG 不会被覆盖。比较出图画质时优先检查原图。

## 开发验证

所有自动测试使用合成图包、合成图片和假模型，不连接真实机器人、不产生出图或 LLM 费用。模型权重未安装时明确错误，不为了测试自动下载。Mac Metal 与实际系统钥匙串仍需在 Mac 原生构建中验证。

```sh
npm ci
npm run typecheck
npm run build
npm run test
npm run check:ui
npm run test:browser
python3 scripts/test-library-check.py
cd src-tauri
cargo test --offline --lib
```

Linux开发环境不能生成macOS `.app` / `.dmg`。Mac上拉取后运行 `npm run tauri build`，或用 `npm run tauri dev` 体验；不要在应用数据目录执行 git/npm。
