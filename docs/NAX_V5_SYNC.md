# NAX V5 画师库

从 v0.5.15 起，在「画师词典」上方选择「法典」或「NAX V5」。首次点「同步」后，NAX 的完整公开画师目录及 WebP 展示图会下载到本机，可复用加入 / 不加入 / 未定、备注、黑名单、预览和画师串复制。

来源是 <https://nax.moe/?gallery=danbooru-artist-tags-2-v5>，由 u/Carlyone (Zelest) 维护。样例使用 V5 Full；它主要展示单画师效果。详情保留来源、署名和该画师样例的完整提示词与生成设置，画师库条目本身只存画师标签，避免把示例人物与场景混进导出画师串。图片按网站公开 WebP 展示图下载，没有公开原图时不构造原图链接。

## 同步与保存

- 每次常规同步都会读取 NAX 的完整编号页；法典没有新 release 时也会检查 NAX。来源分页、V5 设置、条目和 CDN 地址校验完成，重查首页确认目录没有变化，才入库。
- NAX 的 book ID 是 `nax_v5_artist`，快照 release 是 `nax-v5-<目录哈希前16位>`。法典的 `latest_release` 保持自己的版本；NAX 的本次新增和更新批次用它自己的快照。
- 条目 ID 根据精确画师标签生成，分页或排序变化不会改 ID。投票变化不会制造版本或触发重复下载。新增条目默认为未定；同步不改用户选择、备注或审计记录。
- 非原子分页中暂时消失的条目保留，避免网站更新期间把旧选择误标下架。跨页的同画师同图片条目会去重；分页失败、截断或来源冲突会保留旧目录。另一来源仍可更新，结束消息和日志明确报告部分完成。
- 展示图复用限速、并发、校验、取消与断点续传队列。首次图库较大，耗时取决于带宽和条目数；之后只补新增、变化或缺失的图片。NAX 的本地文件名取哈希，避免长百分号编码文件名超出文件系统限制。
- 已安装本地编码器时，同步继续补齐 NAX 的画风索引；首次大量编码可能耗时。既有法典向量可复用，均值使用新命名空间重算。

## 升级与导出

在「设置 → 软件更新」准备并安装 v0.5.15。Linux 开发环境无法生成 macOS 安装包，内置更新仍使用 Mac 本机工具链构建。

数据库迁移 008 只重建 `artist_library` 视图，将 NAX 纳入画师库；不改已有条目、筛选、历史和实验数据。升级前由现有更新流程备份数据库。NAX 已加入的条目参与画师库导出、黑名单过滤和重复画师去重；完整池导出保留独立来源。

验证使用合成库、合成 HTML 和公开目录元数据，不上传或修改用户真实数据库，不调用模型或生图。覆盖分页与 URL 校验、稳定 ID、选择和下载缓存保留、旧版升级、导出、索引检索和浏览器来源切换。
