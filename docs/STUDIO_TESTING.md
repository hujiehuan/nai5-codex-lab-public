# 总实验室离线验证

`npm run test:studio` 运行三种模式的真实 Vue 界面与合成接口，检查共同输入冻结、构思和出图分离、相同请求 ID 重试、取消、工作区恢复、错误态、旧路由重定向，并在 1280 / 390 像素及深浅色下量测页面溢出、点击目标和文字对比度。结果和截图位于 `/tmp/nai5-studio-probe`，不会进入仓库。

`npm run test:browser` 运行图库检查、全站 smoke 和总实验室。`npm run typecheck`、`npm run build`、`npm run test` 与 `npm run check:ui` 继续适用。

资料、图片与 API 凭据均使用合成值。JPEG 控件生成衍生副本，不修改 PNG 原图或生图参数。本地编码器的比较准确率只使用已人工标注且有有效判断的图对，缺失判断不当作负例。视觉模型以图 1 为基准，从同批全部候选中返回最多三个不重复名次；模型批内分数不计入本地编码准确率。

专项同时覆盖：开始请求尚未返回时停止、响应丢失后沿原请求 ID 确认并停止、运行状态恢复首读失败后的重新关联，以及工作区读取失败不覆盖存档。画风比较保留最近 10 次完整结果；重开后不重新调用模型，视觉空排名不补造候选，本地图对缺失判断不算零分。
