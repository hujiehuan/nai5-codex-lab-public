# 画风模型对比（v0.4.0）

这版先解决配方丢失，再提供同图对比。画风词典的原始 `tags` 只去首尾空白，画师、正负权重、质量词、线条和配色词都保留。检索、复制、精准反推、指定重画、筛选画风池导出使用同一完整配方；相同画师但不同风格词或权重不再合并。社区图包不参与画风索引或检索。

## 模型和准备工作

| 模型 | 用途 | 下载量（十进制约值） | 准备 |
|---|---|---:|---|
| [CLIP ViT-B/32](https://huggingface.co/openai/clip-vit-base-patch32) | 旧版通用向量基线，512 维 | 605 MB | 复用既有画风词典向量；原来图包的向量不再参与 |
| [MegaStyle-Encoder](https://github.com/Tencent/MegaStyle) | 专用画风向量，1152 维 | 857 MB | 下载后补齐此模型的画风词典索引 |
| [CSD ViT-L](https://huggingface.co/tomg-group-umd/CSD-ViT-L) | 专用画风向量，768 维 | 2.44 GB | 下载后补齐此模型的画风词典索引 |
| [Kaloscope 2.0](https://huggingface.co/heathcliff01/Kaloscope2.0) | 39,261 个画师类别 | 735 MB | 使用[社区 ONNX 转换](https://huggingface.co/DraconicDragon/Kaloscope-onnx)，不建图库索引 |
| [Camie Tagger v2](https://huggingface.co/Camais03/camie-tagger-v2) | 从模型的 70,527 个类别中取 7,007 个画师类别 | 797 MB | 官方 ONNX，不建图库索引 |

在设置页逐个下载，或点击下载全部。模型固定上游版本，权重及分类标签映射校验 SHA256；中断的下载可继续，校验完成才作为已下载文件。分类器还会自动准备官方 ONNX Runtime 1.22（Apple Silicon Mac 约 26 MB，两个分类器共用），不需要用户安装 Python。首次整套准备需要数 GB 磁盘和下载流量；权重不进入 Git。

三个向量模型遵从 Auto / Metal / CPU 设置；两个分类器使用 CPU。模型目录、向量和均值按模型 ID 分开。切换回 CLIP 无需重算；同一模型只补新图或换图，暂停后继续保留已完成部分。每种新向量模型仍必须计算一次自己的索引，不能把 CLIP 向量直接拿给 MegaStyle 或 CSD。

## 怎么比较

1. 设置页下载模型，为要比较的向量模型点「补齐索引」。可以先只准备一种新模型。
2. 反推实验室选同一张原图，在画风反推面板点「同图对比」。所有已就绪模型顺序运行，各组分别显示候选和耗时；某一组失败不会丢掉其他组结果。
3. 向量组返回画风词典条目，显示完整配方，可直接复制或「用它重画」。画师识别组只显示标签预测，复制时补 `artist:` 前缀；分类概率不变成 NovelAI 权重。
4. 比较重画时固定原图、反推标签、角色、生成模型、种子和张数，只改变画风配方。直接肉眼看线条、配色、阴影、涂抹质感和完成度；不要用不同编码器的分数大小判断哪个模型更好。

「减库均值」只是检索选项，不表示人物/构图内容已经去除。专用模型默认建议不减均值，CLIP 保留原来的默认；同图对比使用本次选定的相同开关。画师分类识别不了原图的精确混合权重，也不能保证找到原始作者或生成提示词。即使完整配方已知，生成模型、种子、内容和其他生成参数也会改变最终画面。

## 已验证与未验证

2026-09-07 在 Linux CPU 下载并校验所有权重。CSD 与作者官方 PyTorch 图像塔及 style projection 对拍，MegaStyle 与 HF Transformers 的 SiglipVisionModel pooler_output 对拍；渐变图样例余弦均约 1.0，最大逐维差分别为 4.48e-7 和 2.00e-7。分类器已运行真实 ONNX，并对照官方 Pillow 预处理的两张测试输入。以上只验证实现一致性与可运行性，没有证明哪种模型在用户 NovelAI 图片上效果最好。

Mac Metal 编译、实际 GPU 输出、M5 Pro 速度和分类器动态库加载仍需 Mac 真机验收。模型下载在开发环境的验证缓存中完成；用户 Mac 仍需在更新后的设置页下载。插件 `/反推` 指令仍沿用画风池抽取，推送完整库不会自动接通服务器向量检索。

2026-09-07 用户完成一轮 Mac 画风重画对照，反馈 MegaStyle 最符合其还原需求；这是该用户本轮图片与参数下的主观验收结论，不代表所有图片上的模型排名。截图确认 MegaStyle 已下载、索引 1313/1313。本次再次校验验证缓存中的 `megastyle-siglip-so400m/megastyle_encoder.pth`，856600406 字节、SHA256 `79d08343d9208e8348c9f2d61fc627988fd5ad34dda7e977db9a6ead19078d56`，与固定目录一致；无需重复下载。未来插件端接入时可复用 Mac 的同模型索引，服务器仅为新查询图编码并检索；当前尚未部署这段在线流程。
